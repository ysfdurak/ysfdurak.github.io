be used to, get used to

Alışkanlık yapıları · B2 Orta seviye İngilizce dilbilgisi

used to, be used to, get used to

Bu üç yapı birbirine benzer ama anlamları farklıdır. used to + fiil (A2): eskiden yapardım. be used to + -ing / isim: alışkın olmak. get used to + -ing / isim: alışmak (süreç).

YapıAnlamÖrnek
used to + fiileskiden ... -ırdıI used to live in a village.
be used to + -ing / isim... -e alışkın olmakI'm used to living alone.
get used to + -ing / isim... -e alışmakI'm getting used to the cold weather.

Tüm zamanlarda

be used to ve get used to her zamanda kullanılabilir: I wasn't used to the food. You'll soon get used to it. She has got used to her new job. (used to + fiil ise sadece geçmişte vardır.)

Türkçeden farkı: Türkçedeki "alışkın olmak" be used to'nun, "alışmak" get used to'nun karşılığıdır. Buradaki to bir edattır, bu yüzden arkasından -ing gelir: "I'm used to working." "I'm used to work" yanlıştır (ya da "işe alışkınım" anlamına gelir). used to + fiil (eskiden) ile karıştırmamak önemli.
