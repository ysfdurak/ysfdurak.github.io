Complex hypotheticals

Karmaşık varsayımlar · C2 Üst düzey seviye İngilizce dilbilgisi

Karmaşık varsayımlar

C2'de koşul ve varsayım yapıları birleştirilerek ince anlam farkları yaratılır. B2 ve C1'de karma koşulları ve devrik koşulları gördük; burada daha ileri kullanımlara bakıyoruz.

YapıÖrnekAnlam
were to + fiilIf the sun were to disappear, life would end.Çok uzak, teorik varsayım
if it weren't / hadn't been forIf it weren't for you, I'd be lost.... olmasa / olmasaydı
if ... should happen toIf you should happen to see him, tell him.Olur da ... görürsen
if only + would / hadIf only it would stop raining!Keşke (şikâyet / pişmanlık)
what if + past perfectWhat if we had taken the other road?Ya ... -seydik?
as if + past perfectHe talks as if he had been there.Sanki ... -mış gibi

would, could, might ile sonuçlar

Sonuç kısmında would yerine could (yetenek), might (olasılık), should (resmî) kullanılarak anlam inceltilebilir: If I had known, I might have acted differently. Ayrıca koşul ima edilebilir: I wouldn't do that (if I were you). A true friend would have helped.

Türkçeden farkı: Türkçede varsayımlar çoğunlukla "-se, -seydi" ile kurulur ve uzaklık derecesi bağlamdan anlaşılır. İngilizcede "were to" yapısı olayın çok uzak bir ihtimal olduğunu açıkça gösterir. "If it weren't for..." (… olmasa) ve "If it hadn't been for..." (… olmasaydı) kalıpları Türkçedeki "-sayesinde" anlamını tersten verir.

Kendini dene

If the government ___ to raise taxes again, there would be protests.

Seçenekler: were / was being / would

Cevap: were. were to: uzak varsayım.

"A good teacher would have noticed." Ne ima ediliyor?

Seçenekler: Öğretmen fark etti. / Öğretmen fark etmedi; iyi bir öğretmen olsaydı fark ederdi.

Cevap: Öğretmen fark etmedi; iyi bir öğretmen olsaydı fark ederdi.. İma edilen koşul.

___ it not for her support, I would have given up.

Seçenekler: Were / Had / If

Cevap: Were. Were it not for.

If you should ___ to pass the bakery, could you buy some bread?

Seçenekler: happen / happened / be happening

Cevap: happen. should happen to.

What if they ___ the truth earlier? (geçmiş)

Seçenekler: knew / had known / would know

Cevap: had known. what if + past perfect.
