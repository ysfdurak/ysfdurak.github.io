so / such, so that, in order to

Sonuç ve amaç · B1 Orta öncesi seviye İngilizce dilbilgisi

so ve such: o kadar ... ki

so ve such bir özelliği güçlendirir ve çoğu zaman ardından that ile bir sonuç gelir. Fark, arkasından ne geldiğidir.

KelimeArkasındanÖrnek
sosıfat / zarfIt was so cold (that) we stayed in.
somuch / many / little / fewThere were so many people!
such(a / an) + sıfat + isimIt was such a cold day (that) we stayed in.
suchsayılamayan / çoğul isimThey are such nice people.

Amaç: so that, in order to, to

Amaç bildirmek için to + fiil (A2), in order to + fiil (daha resmî) ya da so that + cümle kullanılır. so that'ten sonra genellikle can / could / will / would gelir.

  • I left early to catch the train.Treni yakalamak için erken çıktım.
  • She studied hard in order to pass the exam.Sınavı geçmek için çok çalıştı.
  • I'll write it down so that I don't forget.Unutmamak için not alacağım.
  • He spoke slowly so that we could understand.Anlayabilelim diye yavaş konuştu.
Türkçeden farkı: Türkçedeki "o kadar ... ki" yapısının karşılığı so / such ... that'tir. Kural basit: sadece sıfat varsa so, sıfattan sonra isim de varsa such: "o kadar güzel" = so beautiful; "o kadar güzel bir gün" = such a beautiful day. "-sın diye / -mak için" anlamında cümle gelecekse so that kullanılır.
