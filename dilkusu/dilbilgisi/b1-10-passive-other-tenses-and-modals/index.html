Passive: other tenses and modals

Edilgen yapı: diğer zamanlar · B1 Orta öncesi seviye İngilizce dilbilgisi

Diğer zamanlarda edilgen

Edilgen yapıda zaman her zaman be fiiliyle gösterilir; ana fiil hep V3 kalır.

ZamanEdilgenÖrnek
present continuousam / is / are being + V3The road is being repaired.
present perfecthave / has been + V3My car has been stolen!
past perfecthad been + V3The work had been finished.
future (will)will be + V3The results will be announced tomorrow.
going toam / is / are going to be + V3The house is going to be sold.

Modal fiillerle edilgen

can, must, should, might gibi modal fiillerden sonra be + V3 gelir: This form must be signed. The work can't be done today. Children should be protected.

Türkçeden farkı: Türkçede "yapılıyor, yapıldı, yapılmıştı, yapılacak, yapılabilir" eklerle kolayca kurulur. İngilizcede her biri için be fiilinin uygun biçimi seçilmelidir. Bir ipucu: önce cümleyi Türkçe zamanına göre düşünün, sonra "be"yi o zamana koyup V3 ekleyin.

Sık yapılan hatalar

YanlışDoğruNeden
The road is repaired now. (şu an)The road is being repaired now.Şu an: is being.
It will finished tomorrow.It will be finished tomorrow.will be + V3.
The room has cleaned.The room has been cleaned.has been + V3.

Kendini dene

The new hospital ___ next year.

Seçenekler: will open / will be opened / is opened

Cevap: will be opened. Gelecek edilgen.

Mobile phones ___ in the exam room.

Seçenekler: mustn't use / mustn't be used / mustn't used

Cevap: mustn't be used. modal + be + V3.

A new bridge ___ over the river at the moment.

Seçenekler: is building / is being built / has built

Cevap: is being built. Şu an edilgen.

All the tickets ___ already ___.

Seçenekler: have / sold / have / been sold / are / sold

Cevap: have / been sold. has / have been + V3.

The winner ___ next week.

Seçenekler: will be announced / will announce / is announce

Cevap: will be announced. Gelecek edilgen.
