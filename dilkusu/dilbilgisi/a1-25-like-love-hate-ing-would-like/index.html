like / love / hate + -ing, would like

Sevmek ve istemek · A1 Başlangıç seviye İngilizce dilbilgisi

like / love / hate + -ing

Sevdiğimiz ya da sevmediğimiz eylemlerden söz ederken like, love, enjoy, hate, don't mind gibi fiillerden sonra fiil-ing kullanılır.

FiilAnlamÖrnek
loveçok sevmekI love swimming.
like / enjoysevmek, keyif almakShe likes reading. We enjoy cooking.
don't mindsorun etmemekI don't mind waiting.
don't likesevmemekHe doesn't like running.
hatenefret etmekThey hate getting up early.

would like: kibar istek

would like ('d like) "isterim / ister misin" anlamına gelen kibar bir kalıptır; want'tan daha naziktir. Ardından isim ya da to + fiil gelir.

KalıpÖrnekAnlam
would like + isimI'd like a coffee, please.Bir kahve rica ediyorum.
would like + to + fiilI'd like to go home.Eve gitmek istiyorum.
Would you like ...?Would you like some tea?Biraz çay ister misin?
Would you like to ...?Would you like to come?Gelmek ister misin?

like ile would like farkı

I like coffee = Genel olarak kahveyi severim. I'd like a coffee = Şu an bir kahve istiyorum. Do you like dancing? = Dans etmeyi sever misin? Would you like to dance? = Dans etmek ister misin? (şimdi, davet)

Türkçeden farkı: Türkçede "yüzmeyi severim" derken fiil isim olur (-mayı). İngilizcede bunun karşılığı -ing'dir: swimming. "I like swim" yanlıştır. Bir şey isterken "I want" yerine "I'd like" demek daha kibardır, özellikle restoran ve dükkânlarda.
