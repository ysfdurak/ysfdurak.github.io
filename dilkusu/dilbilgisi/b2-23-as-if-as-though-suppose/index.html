as if, as though, suppose

Sanki, varsayalım · B2 Orta seviye İngilizce dilbilgisi

as if / as though: sanki

as if ve as though "sanki, -mış gibi" anlamındadır. Gerçek olabilecek bir izlenim için normal zaman: It looks as if it's going to rain. Gerçek olmayan, hayalî bir durum için geçmiş zaman: He talks as if he knew everything. (Her şeyi biliyormuş gibi konuşuyor; aslında bilmiyor.)

DurumYapıÖrnek
olası izlenimpresentYou look as if you need a rest.
gerçek dışı (şimdi)past simple / wereShe treats me as if I were a child.
gerçek dışı (geçmiş)past perfectHe looked as if he had seen a ghost.

suppose / supposing / what if

Varsayım yapmak ve olasılık tartışmak için suppose, supposing ve what if kullanılır. Olası durumlar için present, hayalî durumlar için past: Suppose you lose your job, what will you do? / Supposing you won the lottery, what would you do? What if he finds out?

like ile as if

Konuşma dilinde as if yerine like kullanılır: You look like you're tired. Resmî yazıda as if tercih edilir.

Türkçeden farkı: Türkçedeki "-mış gibi" (biliyormuş gibi, hayalet görmüş gibi) as if / as though ile karşılanır. Gerçek dışılık zaman kaydırılarak gösterilir: "biliyormuş gibi" = as if he knew. "Ya ... -se?" (Ya öğrenirse?) yapısı için "What if ...?" çok doğal bir karşılıktır.

Kendini dene

He behaves as if he ___ the boss. (değil)

Seçenekler: is / were / will be

Cevap: were. Gerçek dışı: were.

It looks as though it ___ snow. (bulutlar var)

Seçenekler: is going to / was going to / had

Cevap: is going to. Olası izlenim.

You sound as if you ___ a cold.

Seçenekler: have / had had / would have

Cevap: have. Olası izlenim.

He spends money as if he ___ a millionaire.

Seçenekler: is / were / has been

Cevap: were. Gerçek dışı.

___ you could live anywhere, where would you go?

Seçenekler: Supposing / What if / As if

Cevap: Supposing. Hayalî varsayım.
