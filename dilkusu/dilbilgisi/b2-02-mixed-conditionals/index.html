Mixed conditionals

Karma koşul cümleleri · B2 Orta seviye İngilizce dilbilgisi

Geçmiş koşul, şimdiki sonuç

Karma koşul cümleleri iki farklı zamanı birleştirir. En yaygın tipi: geçmişte farklı olsaydı, şimdi sonuç farklı olurdu. If + past perfect, would + yalın fiil.

  • If I had studied medicine, I would be a doctor now.Tıp okusaydım şimdi doktor olurdum.
  • If we hadn't missed the flight, we'd be in Rome now.Uçağı kaçırmasaydık şimdi Roma'da olurduk.

Şimdiki koşul, geçmiş sonuç

Diğer tipte, şimdiki (genel) bir durum geçmişteki bir sonucu etkiler: If + past simple, would have + V3. If I were braver, I would have said something. (Daha cesur biri olsaydım, bir şey söylerdim.) If he didn't speak English, he wouldn't have got the job.

Türkçeden farkı: Türkçede "-seydi ... -urdu" yapısı zaman açısından esnektir: "Tıp okusaydım şimdi doktor olurdum." İngilizcede her kısmın zamanını ayrı düşünmek gerekir: koşul geçmişteyse past perfect, sonuç şimdiyse would + yalın fiil. "now" kelimesi genellikle sonucun şimdide olduğunun işaretidir.

Kendini dene

If I had taken the job, I ___ in London now.

Seçenekler: would live / would have lived / will live

Cevap: would live. Şimdiki sonuç: would + fiil.

If I ___ afraid of flying, I would have gone with you.

Seçenekler: wasn't / hadn't been / am not

Cevap: wasn't. Genel durum: past simple.

If you had listened to me, you ___ in this mess now.

Seçenekler: wouldn't be / wouldn't have been / won't be

Cevap: wouldn't be. Şimdiki sonuç.

If he ___ so lazy, he would have finished the project.

Seçenekler: wasn't / hadn't been / isn't

Cevap: wasn't. Genel durum.

If I ___ that ticket, I would be a millionaire now.

Seçenekler: bought / had bought / buy

Cevap: had bought. Geçmiş koşul.
