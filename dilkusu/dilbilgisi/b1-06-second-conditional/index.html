Second conditional

İkinci tip koşul · B1 Orta öncesi seviye İngilizce dilbilgisi

Hayalî ve olası olmayan durumlar

İkinci tip koşul, şu an ya da gelecekte gerçek olmayan, olması pek mümkün olmayan, hayalî durumları anlatır. if kısmında past simple, sonuç kısmında would + yalın fiil kullanılır. Geçmiş zaman biçimi kullanılsa da anlam şimdi veya gelecektir.

If kısmı (past simple)Sonuç (would)
If I had more money,I would travel the world.
If she lived nearer,we'd see her more often.
If I didn't have a car,I'd take the bus.

If I were you

be fiili ikinci tip koşulda her kişi için were olabilir; özellikle tavsiye kalıbında: If I were you, I'd accept the offer. (Yerinde olsam teklifi kabul ederdim.) Günlük konuşmada "If I was" da duyulur.

Birinci mi, ikinci mi?

Olasılığı gerçekçi görüyorsak birinci tip: If I get the job, I'll move. (İşi alma ihtimalim var.) Hayalî ya da uzak görüyorsak ikinci tip: If I won the lottery, I'd buy a house. (Pek mümkün değil.)

Türkçeden farkı: Türkçedeki "-se ... -ardı" (paramız olsa alırdık) yapısı ikinci tip koşulun tam karşılığıdır. Dikkat: if kısmında would kullanılmaz. "If I would have money" yanlış, "If I had money" doğrudur.

Kendini dene

If I ___ the answer, I would tell you.

Seçenekler: know / knew / will know

Cevap: knew. if + past simple.

If I ___ a million dollars, I'd give some to charity.

Seçenekler: win / won

Cevap: won. Hayalî: past.

What would you do if you ___ a ghost?

Seçenekler: see / saw / would see

Cevap: saw. if + past.

If he studied more, he ___ better marks.

Seçenekler: gets / would get / will get

Cevap: would get. Sonuç: would.

If I ___ you, I wouldn't do that.

Seçenekler: am / were / would be

Cevap: were. If I were you.
