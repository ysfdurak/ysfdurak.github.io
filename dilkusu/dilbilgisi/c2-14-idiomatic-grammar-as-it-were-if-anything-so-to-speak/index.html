Idiomatic grammar: as it were, if anything, so to speak

Kalıplaşmış dilbilgisi · C2 Üst düzey seviye İngilizce dilbilgisi

Kalıplaşmış dilbilgisi

İngilizcede bazı kalıplar dilbilgisel olarak "düzensizdir" ama anlamı ve kullanımı sabittir. Bunlar C2 düzeyinde konuşmayı ve yazıyı doğal kılar.

KalıpAnlamÖrnek
as it wereadeta, tabiri caizseHe became, as it were, a father to me.
so to speakdeyim yerindeyseWe're all in the same boat, so to speak.
if anythinghatta, aksineThe situation isn't better. If anything, it's worse.
as suchbu sıfatla, haddi zatındaShe's the manager and, as such, responsible.
for all I knowbildiğim kadarıyla (belki de)For all I know, he's already left.
for all + isim-e rağmenFor all his money, he isn't happy.
as often as notçoğu zamanAs often as not, the train is late.
all butneredeyseThe project is all but finished.
nothing butsadeceHe's caused nothing but trouble.
if nothatta, belki deIt will take months, if not years.

Doğru anlamı seçmek

Bazı kalıplar benzer görünse de zıt anlam taşır: all but = neredeyse (all but impossible = neredeyse imkânsız); anything but = asla, hiç de değil (He's anything but lazy = hiç tembel değil); nothing but = sadece (nothing but lies = sadece yalanlar).

Türkçeden farkı: Türkçede de "tabiri caizse, hatta, -e rağmen, neredeyse" gibi kalıplar vardır ve İngilizcedekilerle aynı işlevi görür. Bu kalıplar kelime kelime çevrilemez; "all but" ile "anything but" gibi çiftler özellikle karıştırılır. Bunları örnek cümleyle birlikte öğrenmek en iyi yöntemdir.

YanlışDoğruNeden

Kendini dene

It's not cheaper. ___, it's more expensive.

Seçenekler: If anything / As such / All but

Cevap: If anything. If anything = aksine.

The war was ___ over. (neredeyse bitmişti)

Seçenekler: all but / nothing but / but all

Cevap: all but. all but = neredeyse.

"He's anything but stupid." ne demek?

Seçenekler: O çok aptal. / O hiç de aptal değil.

Cevap: O hiç de aptal değil.. anything but = hiç de değil.

The task is ___ impossible. (neredeyse)

Seçenekler: all but / anything but / nothing but

Cevap: all but. all but.

The hotel was ___ comfortable. (hiç rahat değildi)

Seçenekler: all but / anything but / nothing but

Cevap: anything but. anything but.
