this / that / these / those

Bu, şu, bunlar, şunlar · A1 Başlangıç seviye İngilizce dilbilgisi

Yakın ve uzak, tekil ve çoğul

this, that, these ve those bir şeyi işaret ederken kullanılır. Yakındaki şeyler için this / these, uzaktaki şeyler için that / those. Tekil isimle this / that, çoğul isimle these / those kullanılır.

Yakın (burada)Uzak (orada)
Tekilthis (bu)that (şu / o)
Çoğulthese (bunlar)those (şunlar / onlar)
  • This book is interesting.Bu kitap ilginç.
  • That house is very old.Şu ev çok eski.
  • These shoes are new.Bu ayakkabılar yeni.
  • Those people are my neighbours.Şu insanlar komşularım.
  • What is this? It's a key.Bu ne? Bir anahtar.

Fiil de uyum gösterir: this / that + is, these / those + are. Cevap verirken this / that yerine it, these / those yerine they kullanılır.

Türkçeden farkı: Türkçede "bu ayakkabılar" deriz, "bu" değişmez. İngilizcede işaret kelimesi de çoğul olur: these shoes ("this shoes" yanlış).
